# Tasks

Conventions for every task: test first (red, then green), `./gradlew` through the Gradle MCP, `ide diagnostics` on touched files, the build green after each task. A test that characterises behaviour that already works says how to see it fail once (a deliberate temporary break); do that before ticking. "D<n>" refers to `design.md`, scenario names to the delta specs in `specs/`. Spring AI APIs are checked against the 2.1.0-RC2 sources, never memory (`spring-ai` skill, Gradle MCP `read_dependency_sources`). Production code of the adjuster lives in `backend/src/main/kotlin/dev/frederikpietzko/springaidemo/backend/adjuster/`, tests next to it under `src/test`. Before starting, refresh this plan against the merged code of the earlier changes (the shared files named in the design's risks) and note any deviation as a decision.
